# Barbearia Nakamura

Site institucional responsivo desenvolvido para a Barbearia Nakamura, localizada em Belém, Pará. O projeto apresenta serviços, valores, galeria, localização e canais de agendamento em uma experiência rápida e acessível.

## Destaques

- Design responsivo para celular, tablet e desktop
- Identidade visual personalizada
- Integração com WhatsApp, Instagram e Google Maps
- Galeria acessível por teclado
- SEO técnico com Open Graph, Schema.org, sitemap e robots.txt
- Fontes hospedadas localmente e imagens otimizadas
- Sem frameworks ou etapa de build

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Schema.org / JSON-LD

## Executar localmente

Como o site utiliza caminhos absolutos para os recursos, execute-o com um servidor HTTP local. Por exemplo, com a extensão **Live Server** do VS Code.

Depois, abra o endereço informado pelo servidor no navegador.

## Estrutura

```text
assets/
  css/       estilos do site
  fonts/     fontes locais
  img/       imagens e identidade visual
  js/        interações da interface
index.html   página principal
```
